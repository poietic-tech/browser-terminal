# v0.6.1 — New repository home

## Changes

- The repository moved to [poietic-tech/browser-terminal](https://github.com/poietic-tech/browser-terminal).
  The package's `homepage`, `repository` and `bugs` fields, the README links,
  the security-reporting link, and the demo site footer now point there. The
  live demos are at <https://poietic-tech.github.io/browser-terminal/>.
- Releases publish through npm trusted publishing (OIDC) with provenance,
  instead of a stored token. The release workflow's dry run warns rather than
  fails on an already-published version, and CI runs on Node 24.

The package name stays `@benjamin-small/browser-terminal`. There are no API or
behaviour changes from v0.6.0.

## Upgrade

Nothing to change. Bump the version if you want the npm page's links to name
the new repository.

## Validation and coverage

- The release workflow's dry run passed on this commit: Rust formatting,
  Clippy, the native and WASM boundary tests, the library build, the demo type
  check, the filesystem contract tests, the Chromium browser suite, the
  publishable check, and the packed tarball installed and booted as a consumer.
- No manual browser or native folder testing beyond that, as no runtime code
  changed.
